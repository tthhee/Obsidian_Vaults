## 一、回归任务 Loss（预测连续数值）

### 1. MSE 均方误差 L2 Loss

#### 原理

公式：

$$
L_{\mathrm{MSE}}=\frac{1}{N}\sum_{i=1}^{N}(y_i-\hat y_i)^2
$$

计算真值与预测值差值的平方均值。平方项会放大大误差，梯度大小与误差近似线性相关，通常易于优化；但对离群点敏感，适合噪声较小、希望重点惩罚大误差的回归任务（如房价、坐标和流量预测）。

#### PyTorch 实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

# 1. 官方原生API（推荐，加速+数值稳定）
mse_criterion = nn.MSELoss()
y_pred = torch.tensor([1.2, 2.3, 3.4])
y_true = torch.tensor([1.0, 2.0, 3.0])
loss = mse_criterion(y_pred, y_true)

# 2. 手写底层实现，直观理解计算逻辑
def mse_loss(y_pred: torch.Tensor, y_true: torch.Tensor) -> torch.Tensor:
    return torch.mean((y_pred - y_true) ** 2)
```

### 2. MAE 平均绝对误差 L1 Loss

#### 原理

公式：

$$
L_{\mathrm{MAE}}=\frac{1}{N}\sum_{i=1}^{N}|y_i-\hat y_i|
$$

对误差取绝对值后求平均，提供线性惩罚；相比 MSE 对离群点更鲁棒，但在误差为 0 处不可微（框架通常使用次梯度），可能导致收敛速度和最终精度不如 MSE 平滑。适合含离群点或重尾噪声的回归任务。

#### PyTorch 实现

```python
# 原生API
mae_criterion = nn.L1Loss()
loss = mae_criterion(y_pred, y_true)

# 手写实现
def mae_loss(y_pred: torch.Tensor, y_true: torch.Tensor) -> torch.Tensor:
    return torch.mean(torch.abs(y_pred - y_true))
```

### 3. Huber Loss（L1+L2 折中损失）

#### 原理

分段公式：

$$
L_\delta(r)=
\begin{cases}
\frac{1}{2}r^2, & |r|\le\delta\\
\delta\left(|r|-\frac{1}{2}\delta\right), & |r|>\delta
\end{cases}
\qquad r=y-\hat y
$$

小误差区间使用二次项，保证零点附近梯度平滑；大误差区间使用斜率为 δ 的线性项，抑制离群点影响。它是 MSE 与 L1 的折中，δ 是误差阈值超参数，常用于目标检测框回归和含噪回归。

#### PyTorch 实现

```python
# 原生API
huber_criterion = nn.HuberLoss(delta=1.0)
loss = huber_criterion(y_pred, y_true)

# 手写实现
def huber_loss(y_pred: torch.Tensor, y_true: torch.Tensor, delta: float = 1.0) -> torch.Tensor:
    if delta <= 0:
        raise ValueError("delta must be positive")
    diff = torch.abs(y_pred - y_true)
    loss = torch.where(
        diff <= delta,
        0.5 * diff ** 2,
        delta * (diff - 0.5 * delta),
    )
    return loss.mean()
```

### 4. Log-Cosh Loss

#### 原理

$$
L_{\mathrm{LogCosh}}=\frac{1}{N}\sum_{i=1}^{N}\log\left(\cosh(y_i-\hat y_i)\right)
$$

令残差为 $r=y-\hat y$。当 $|r|$ 较小时，$\log(\cosh r)\approx r^2/2$，类似 MSE；当 $|r|$ 较大时，$\log(\cosh r)\approx |r|-\log 2$，类似 L1。因此它兼顾零点附近的平滑性和对异常值的鲁棒性，且关于残差处处二阶可导。

#### PyTorch 实现

```python
def log_cosh_loss(y_pred: torch.Tensor, y_true: torch.Tensor) -> torch.Tensor:
    residual = y_pred - y_true
    # 比直接 log(cosh(x)) 更稳定，避免大 x 溢出
    loss = residual + F.softplus(-2.0 * residual) - torch.log(
        torch.tensor(2.0, device=residual.device, dtype=residual.dtype)
    )
    return loss.mean()
```

> 实现利用 $\log(\cosh x)=x+\operatorname{softplus}(-2x)-\log 2$，数值上比直接计算 `torch.log(torch.cosh(x))` 更稳定。

## 二、二分类任务 Loss（Sigmoid 单通道概率输出）

### 1. BCE 二元交叉熵

#### 原理

单样本损失公式：

$$
L_{\mathrm{BCE}}=-\left[y\log\hat y+(1-y)\log(1-\hat y)\right]
$$

基于信息熵衡量真实标签与预测概率分布差异；y=1 时惩罚预测概率偏小，y=0 时惩罚预测概率偏大；配合 Sigmoid 使用，样本均衡场景效果好，正负样本失衡时效果较差。

#### PyTorch 实现

```python
batch_size = 32
logits = torch.randn(batch_size, 1)  # 网络原始输出，未经过sigmoid
y_true = torch.randint(0, 2, (batch_size, 1)).float()

# 方案1：BCELoss 输入必须是sigmoid后的概率
bce_prob_criterion = nn.BCELoss()
y_pred_prob = torch.sigmoid(logits)
loss1 = bce_prob_criterion(y_pred_prob, y_true)

# 方案2：BCEWithLogitsLoss（推荐，内置sigmoid，数值更稳定）
bce_logit_criterion = nn.BCEWithLogitsLoss()
loss2 = bce_logit_criterion(logits, y_true)

# 手写 BCE（输入概率）
def bce_loss(y_pred: torch.Tensor, y_true: torch.Tensor, eps: float = 1e-8) -> torch.Tensor:
    loss = - y_true * torch.log(y_pred + eps) - (1 - y_true) * torch.log(1 - y_pred + eps)
    return torch.mean(loss)
```

### 2. Weighted BCE 加权二元交叉熵

#### 原理

引入正样本权重 $\alpha$ 平衡类别数量差距。下面的公式只对正类加权；在 PyTorch 中对应 `BCEWithLogitsLoss(pos_weight=...)`：

$$
L_{\mathrm{WBCE}}=-\left[\alpha y\log\hat y+(1-y)\log(1-\hat y)\right]
$$

当正类是少数类时增大 $\alpha$，可以提高正类错误对梯度的贡献；如果需要同时控制正、负类的样本权重，应使用显式的逐元素 `weight` 或自行构造权重。

#### PyTorch 实现

```python
# pos_weight 为正样本权重，根据样本比例设置
pos_weight = torch.tensor([5.0])
weighted_bce_criterion = nn.BCEWithLogitsLoss(pos_weight=pos_weight)
loss = weighted_bce_criterion(logits, y_true)
```

### 3. Focal Loss（二分类）

#### 原理

$$
L_{\mathrm{Focal}}=-\alpha(1-\hat y)^\gamma y\log\hat y-(1-\alpha)\hat y^\gamma(1-y)\log(1-\hat y)
$$

调制因子 $(1-p_t)^\gamma$ 压低易分类样本的损失权重，使模型更关注难样本；$\gamma$ 控制抑制强度，$\alpha$ 用于类别平衡。它常用于目标检测和其他前景/背景极不均衡任务。

#### PyTorch 实现

```python
def focal_loss_binary(logits: torch.Tensor, y_true: torch.Tensor, alpha: float = 0.25, gamma: float = 2.0, eps: float = 1e-8) -> torch.Tensor:
    p = torch.sigmoid(logits)
    loss_pos = -alpha * torch.pow(1 - p, gamma) * y_true * torch.log(p + eps)
    loss_neg = -(1 - alpha) * torch.pow(p, gamma) * (1 - y_true) * torch.log(1 - p + eps)
    total_loss = loss_pos + loss_neg
    return torch.mean(total_loss)
```

## 三、多分类任务 Loss（Softmax 多通道分类）

### 1. CrossEntropy 标准交叉熵

#### 原理

先 Softmax 归一化 logits 为概率：

$$
\hat y_k=\frac{e^{z_k}}{\sum_j e^{z_j}}
$$

损失：

$$\mathcal{L}_{CE} = -\sum_{k=1}^C y_k \log\hat{y}_k$$

$y_k$ 是 one-hot 标签，仅真实类别位置为 1，简化为：

$$
L_{\mathrm{CE}}=-\log\hat y_{\mathrm{true}}
$$

对 one-hot 标签而言，交叉熵等价于最小化真实分布与预测分布之间的交叉熵，也等价于在真实分布固定时最小化 $D_{\mathrm{KL}}(P\|Q)$。PyTorch 的 `CrossEntropyLoss` 应输入原始 logits 和类别索引，不要提前 Softmax。

#### PyTorch 实现

```python
batch_size = 32
num_class = 10
logits = torch.randn(batch_size, num_class)
y_label = torch.randint(0, num_class, (batch_size,))  # 类别索引，非one-hot

# 原生API（推荐）
ce_criterion = nn.CrossEntropyLoss()
loss = ce_criterion(logits, y_label)

# 手写one-hot版本交叉熵
def cross_entropy_onehot(logits: torch.Tensor, y_onehot: torch.Tensor, eps: float = 1e-8) -> torch.Tensor:
    softmax = torch.softmax(logits, dim=-1)
    loss = -torch.sum(y_onehot * torch.log(softmax + eps), dim=-1)
    return torch.mean(loss)
```

### 2. Label Smooth CrossEntropy 标签平滑交叉熵

#### 原理

软化硬 one-hot 标签，降低模型过度自信和过拟合风险。常见定义如下：

$$
\tilde y_k=
\begin{cases}
1-\epsilon, & k=\text{真实类别}\\
\frac{\epsilon}{C-1}, & k\ne\text{真实类别}
\end{cases}
$$

其中 $\epsilon\in[0,1]$ 是平滑系数。注意：下面的手写实现必须与公式采用同一约定；这里采用“非真实类别总共分配 $\epsilon$”的约定，因此分母是 $C-1$。

#### PyTorch 实现

```python
class LabelSmoothCE(nn.Module):
    def __init__(self, eps: float = 0.1):
        super().__init__()
        self.eps = eps

    def forward(self, logits: torch.Tensor, labels: torch.Tensor) -> torch.Tensor:
        n_class = logits.size(-1)
        one_hot = torch.zeros_like(logits).scatter(1, labels.unsqueeze(1), 1.0)
        smooth_label = one_hot * (1 - self.eps) + (1 - one_hot) * self.eps / (n_class - 1)
        log_probs = torch.log_softmax(logits, dim=-1)
        loss = -torch.sum(smooth_label * log_probs, dim=-1)
        return torch.mean(loss)

# 使用示例
smooth_ce_criterion = LabelSmoothCE(eps=0.1)
loss = smooth_ce_criterion(logits, y_label)
```

### 3. 多分类 Focal Loss

#### 原理

$$
L_{\mathrm{Focal-Multi}}=-(1-\hat y_{\mathrm{true}})^\gamma\log\hat y_{\mathrm{true}}
$$

在多分类交叉熵基础上增加调制因子，压制大量易分类样本梯度，适用于类别不均衡多分类场景。

#### PyTorch 实现

```python
def focal_loss_multi(logits: torch.Tensor, labels: torch.Tensor, gamma: float = 2.0) -> torch.Tensor:
    ce_reduction_none = nn.CrossEntropyLoss(reduction="none")
    logp = -ce_reduction_none(logits, labels)
    p = torch.exp(logp)
    loss = -torch.pow(1 - p, gamma) * logp
    return torch.mean(loss)
```

## 四、图像分割专用 Loss

### Dice Loss + BCE-Dice 组合损失

#### 原理

Dice 系数衡量预测与真值前景重叠度：

$$
\operatorname{Dice}(X,Y)=\frac{2|X\cap Y|}{|X|+|Y|},
\qquad L_{\mathrm{Dice}}=1-\operatorname{Dice}(X,Y)
$$

直接优化区域重叠，对前景像素很少的医学分割和小目标分割通常比单独 BCE 更关注前景；但单独使用时可能出现梯度不稳定或区域尺度敏感，工程中常与 BCE 联合使用。实际实现通常按 batch/类别分别计算 Dice，再求平均，而不是把所有类别和样本无条件混在一起。

#### PyTorch 实现

```python
def dice_loss(logits: torch.Tensor, y_true: torch.Tensor, eps: float = 1e-6) -> torch.Tensor:
    """
    logits: [B, C, H, W] 网络原始输出
    y_true: [B, C, H, W] one-hot真值
    """
    pred = torch.sigmoid(logits)
    inter = torch.sum(pred * y_true, dim=(2, 3))
    union = torch.sum(pred, dim=(2, 3)) + torch.sum(y_true, dim=(2, 3))
    dice_coeff = (2. * inter + eps) / (union + eps)
    return 1 - torch.mean(dice_coeff)

# BCE + Dice 联合损失（分割通用）
def bce_dice_combined_loss(logits: torch.Tensor, y_true: torch.Tensor) -> torch.Tensor:
    bce = nn.BCEWithLogitsLoss()(logits, y_true)
    dice = dice_loss(logits, y_true)
    return bce + dice
```

## 五、目标检测框回归 CIoU Loss

### 原理

IoU 只关注重叠区域，无重叠时优化信号较弱；GIoU 增加外接框约束；DIoU 增加中心距离惩罚；CIoU 进一步加入长宽比惩罚。CIoU 常用于目标检测框回归，但并非所有现代检测器的默认配置，具体应以模型实现为准。

### PyTorch 实现

```python
def box_ciou_loss(pred_boxes: torch.Tensor, target_boxes: torch.Tensor, eps: float = 1e-6) -> torch.Tensor:
    """
    boxes 格式 [x1, y1, x2, y2]
    pred_boxes / target_boxes: [N, 4]
    """
    b1_x1, b1_y1, b1_x2, b1_y2 = pred_boxes.unbind(-1)
    b2_x1, b2_y1, b2_x2, b2_y2 = target_boxes.unbind(-1)

    # 交集计算
    inter_x1 = torch.max(b1_x1, b2_x1)
    inter_y1 = torch.max(b1_y1, b2_y1)
    inter_x2 = torch.min(b1_x2, b2_x2)
    inter_y2 = torch.min(b1_y2, b2_y2)
    inter_area = torch.clamp(inter_x2 - inter_x1, min=0) * torch.clamp(inter_y2 - inter_y1, min=0)

    # 并集与IoU
    area1 = (b1_x2 - b1_x1) * (b1_y2 - b1_y1)
    area2 = (b2_x2 - b2_x1) * (b2_y2 - b2_y1)
    union_area = area1 + area2 - inter_area
    iou = inter_area / (union_area + eps)

    # 外接矩形
    cw = torch.max(b1_x2, b2_x2) - torch.min(b1_x1, b2_x1)
    ch = torch.max(b1_y2, b2_y2) - torch.min(b1_y1, b2_y1)

    # 中心距离惩罚项
    cx1, cy1 = (b1_x1 + b1_x2) / 2, (b1_y1 + b1_y2) / 2
    cx2, cy2 = (b2_x1 + b2_x2) / 2, (b2_y1 + b2_y2) / 2
    center_dist = (cx1 - cx2) ** 2 + (cy1 - cy2) ** 2
    corner_dist = cw ** 2 + ch ** 2 + eps
    dist_penalty = center_dist / corner_dist

    # 长宽比惩罚项；clamp 防止退化框导致除零或负宽高
    w1 = torch.clamp(b1_x2 - b1_x1, min=eps)
    h1 = torch.clamp(b1_y2 - b1_y1, min=eps)
    w2 = torch.clamp(b2_x2 - b2_x1, min=eps)
    h2 = torch.clamp(b2_y2 - b2_y1, min=eps)
    ar_diff = torch.atan(w2 / h2) - torch.atan(w1 / h1)
    v = (4 / (torch.pi ** 2)) * torch.pow(ar_diff, 2)
    alpha = v / (1 - iou + v + eps)

    ciou = iou - dist_penalty - alpha * v
    return torch.mean(1 - ciou)
```

## 六、表征 / 对比学习 Loss

### 1. Triplet Loss 三元组损失

#### 原理

$$
L_{\mathrm{Triplet}}=\max\left(\|f_a-f_p\|_2^2-\|f_a-f_n\|_2^2+\alpha,0\right)
$$

输入锚样本a、同类正样本p、异类负样本n；约束同类特征距离比异类至少小α间隔，仅对不满足约束的样本计算损失，用于人脸识别、图像检索。

#### PyTorch 实现

```python
class TripletLoss(nn.Module):
    def __init__(self, margin: float = 1.0):
        super().__init__()
        self.margin = margin

    def forward(self, anchor: torch.Tensor, positive: torch.Tensor, negative: torch.Tensor) -> torch.Tensor:
        dist_pos = torch.sum((anchor - positive) ** 2, dim=-1)
        dist_neg = torch.sum((anchor - negative) ** 2, dim=-1)
        loss = torch.maximum(dist_pos - dist_neg + self.margin, torch.zeros_like(dist_pos))
        return torch.mean(loss)
```

### 2. Contrastive Loss 对比损失

#### 原理

给定样本对 $(x_1,x_2)$、标签 $y\in\{0,1\}$ 和特征距离 $d=\|f_1-f_2\|_2$：

$$
L_{\mathrm{Contrastive}}=
\begin{cases}
 d^2, & y=1\\
 \max(\alpha-d,0)^2, & y=0
\end{cases}
$$

同类样本被拉近，异类样本至少保持 $\alpha$ 的距离。该损失需要正负样本对；负样本构造和难例挖掘会显著影响效果。

#### PyTorch 实现

```python
def contrastive_loss(
    f1: torch.Tensor,
    f2: torch.Tensor,
    label: torch.Tensor,
    margin: float = 1.0,
) -> torch.Tensor:
    distance = torch.norm(f1 - f2, p=2, dim=-1)
    positive = label * distance.pow(2)
    negative = (1 - label) * torch.clamp(margin - distance, min=0).pow(2)
    return (positive + negative).mean()
```

### 3. InfoNCE Loss（对比学习主流）

#### 原理

$$
L_{\mathrm{InfoNCE}}
=
-\log\frac{\exp(\operatorname{sim}(q,k^+)/\tau)}{\sum_{i=0}^{N}\exp(\operatorname{sim}(q,k_i)/\tau)}
$$

将对比学习转化为多分类任务，区分 query 的正例与全部负例；$\tau$ 是温度系数，用于缩放相似度的分布。实现时通常先对向量做 L2 归一化，再用点积表示 cosine similarity；同时必须明确 `keys` 中正样本对应的 label 位置。

#### PyTorch 实现

```python
def info_nce_loss(q: torch.Tensor, keys: torch.Tensor, tau: float = 0.1) -> torch.Tensor:
    """
    q: query 向量 [B, D]
    keys: 候选 key 向量 [K, D]；第 i 个 query 的正例必须位于 labels[i]
    """
    q = torch.nn.functional.normalize(q, dim=-1)
    keys = torch.nn.functional.normalize(keys, dim=-1)
    sim_matrix = torch.matmul(q, keys.T) / tau
    # 这里假设 keys 的前 B 个位置分别是每个 query 的正例
    labels = torch.arange(q.shape[0], device=q.device)
    ce_criterion = nn.CrossEntropyLoss()
    return ce_criterion(sim_matrix, labels)
```

## 八、特殊场景 Loss

### 1. KL Divergence KL 散度（分布对齐、知识蒸馏）

#### 原理

KL 散度衡量教师模型软分布与学生模型分布差异：

$$
D_{\mathrm{KL}}(P\|Q)=\sum_x P(x)\log\frac{P(x)}{Q(x)}
$$

高温 $T$ 平滑教师和学生的输出分布，让学生学习类别之间的相对关系，而不只是硬标签。蒸馏时通常使用 $T^2$ 缩放梯度；若同时使用硬标签交叉熵，应再按权重与硬标签损失组合。

### PyTorch 实现

```python
def kl_div_distill_loss(student_logits: torch.Tensor, teacher_logits: torch.Tensor, temp: float = 2.0, eps: float = 1e-8) -> torch.Tensor:
    if temp <= 0:
        raise ValueError("temp must be positive")
    # F.kl_div 的 input 是 log-prob，target 是普通概率分布
    s_log_prob = torch.log_softmax(student_logits / temp, dim=-1)
    t_prob = torch.softmax(teacher_logits.detach() / temp, dim=-1)
    kl = F.kl_div(s_log_prob, t_prob, reduction="batchmean")
    # 按知识蒸馏的常用约定恢复温度缩放
    return kl * temp * temp
```

### 2. Poisson Loss（计数任务）

适合预测非负计数，如人群数量、事件次数和细胞个数。若模型输出为 log-rate $\eta$，令 $\lambda=e^\eta$，忽略与模型无关的常数项后，Poisson 负对数似然为：

$$
L_{\mathrm{Poisson}}=e^{\eta}-y\eta
$$

```python
def poisson_nll_loss(log_rate: torch.Tensor, target: torch.Tensor) -> torch.Tensor:
    if torch.any(target < 0):
        raise ValueError("target count must be non-negative")
    return F.poisson_nll_loss(
        log_rate, target, log_input=True,
        full=False, reduction="mean",
    )
```

### 3. Cosine Embedding Loss

给定标签 $y\in\{1,-1\}$：

$$
L=\begin{cases}
1-\cos(x_1,x_2), & y=1\\
\max(0,\cos(x_1,x_2)-m), & y=-1
\end{cases}
$$

```python
cosine_criterion = nn.CosineEmbeddingLoss(margin=0.0)
label = torch.tensor([1.0, -1.0])
loss = cosine_criterion(x1, x2, label)
```

## 九、损失函数快速选型

| 任务类型 | 首选 Loss | 备选 / 改进 |
|---|---|---|
| 普通回归 | MSE | Huber、MAE（含离群点） |
| 二分类（均衡样本） | BCEWithLogitsLoss | Label Smoothing BCE |
| 二分类（极度不均衡） | Focal Loss / Weighted BCE | 调整采样、BCE + Dice |
| 多分类图像 / NLP | CrossEntropyLoss | Label Smoothing CE、Focal Loss |
| 图像语义分割（小前景） | BCE + Dice Loss | Focal、Tversky、Focal Dice |
| 目标检测框回归 | CIoU / GIoU | DIoU、Huber、L1 |
| 特征检索 / 人脸识别 | Triplet、Contrastive | InfoNCE、Cosine Embedding |
| 自监督预训练 | InfoNCE | SupCon、Barlow Twins |
| 知识蒸馏 | $T^2D_{\mathrm{KL}}$ + CE | Soft Label Loss |
| 计数预测 | Poisson NLL | Negative Binomial NLL |

> 选型原则：先确认任务输出空间和标签形式，再处理不平衡，最后根据异常值、噪声、样本构造和数值稳定性选择损失。必须同时检查 reduction、标签范围、logits/概率输入和张量形状。
