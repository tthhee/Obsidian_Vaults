## 一、根本原因

### 1. BEV 特征分辨率在纵向（x）方向只有 1.2m，且损失在归一化坐标下各向异性

配置里 [bsl_aug.py:82-86](configs/psd-bevlane-j6/v035_3_j6/bsl_aug.py#L82-L86)：

```python
voxel_size_bev_static = [1.2, 0.2, 8]   # x=1.2m, y=0.2m
```

即 BEV 栅格纵向 1.2m、横向 0.2m，**6:1 的各向异性**。query 通过 deformable attention 从这张 BEV 特征上采样（[custom_lanehead_mapqr_v2.py](mmdet3d/models/dense_heads/custom_lanehead_mapqr_v2.py) 里 cross-attn `num_points=4, num_levels=1`），所以 query 能拿到的信息在纵向被量化到 1.2m——弯道远点主要靠"深度→纵向距离"来定位，这个方向恰恰最粗。

更关键的是回归 loss 在**归一化坐标**下算的（[custom_lanehead_mapqr_v2.py:909-913](mmdet3d/models/dense_heads/custom_lanehead_mapqr_v2.py#L909-L913)）：

```python
normalized_pts_targets = normalize_2d_pts(pts_targets, self.pc_range)
loss_pts = self.loss_pts(bound_pts_preds, normalized_pts_targets, ...)
```

而 [nms_free_coder.py:49-57](mmdet3d/core/bbox/coders/nms_free_coder.py#L49-L57) 里 `x / patch_w(153.6)`、`y / patch_h(25.6)`。这意味着**归一化空间里同样的 1 个单位误差，在物理空间 x 方向是 153.6m、y 方向只有 25.6m**。等价于：优化器对横向误差的惩罚是纵向的 6 倍，纵向（沿路方向）误差被"放水"了。这正好对应"远处点沿路/纵向位置不准"。

> 这是我认为**收益最高、改动最小**的一个点：把 L1 回归 loss 改到物理米制（denormalize 后再算），或对 x、y 用各自尺度重新加权，让 loss 在物理空间各向同性。

### 2. 车道线只用 20 个等弧长采样点，弯道曲率欠采样

[bsl_aug.py:101-102](configs/psd-bevlane-j6/v035_3_j6/bsl_aug.py#L101-L102) 设 `fixed_ptsnum_per_gt_line = fixed_ptsnum_per_pred_line = 20`，GT 采样在 [phigent_map_utils.py:350-351](mmdet3d/datasets/phigent_map_utils.py#L350-L351)：

```python
distances = np.linspace(0, line.length, self.fixed_num)
sampled_pts = np.array([line.interpolate(d).coords[0] for d in distances])
```

即**沿弧长均匀取 20 点**。一条最长到 153.6m 的线，平均 7~8m 一个点；急弯（小半径）用 20 个点根本描述不了曲率，远端弯道形状在监督信号层面就是糊的。而且 20 个点的回归 loss 权重完全相等（[custom_lanehead_mapqr_v2.py:492-494](mmdet3d/models/dense_heads/custom_lanehead_mapqr_v2.py#L492-L494) `pts_weights[pos_inds]=1.0`），没有任何距离/曲率加权。

### 3. 方向/曲率监督过弱

[bsl_aug.py:394-396](configs/psd-bevlane-j6/v035_3_j6/bsl_aug.py#L394-L396)：

```python
loss_pts=dict(type="PtsL1Loss", loss_weight=5.0),
loss_dir=dict(type="PtsDirCosLoss", loss_weight=0.005),
loss_dir2=dict(type="PtsL1Loss", loss_weight=0.005),
```

方向 loss（`PtsDirCosLoss` + 前后向量夹角一致性 `loss_dir2`）是约束"相邻点方向/曲率一致"的主要手段，但权重只有 0.005，比回归 loss 小 3 个数量级。这导致远端点可以"平移漂移"而不被方向约束拉住，曲线形状不光滑、曲率失真。

### 4. 深度估计在远距离天然退化 + 深度 bin 固定 1m

[bsl_aug.py:74-79](configs/psd-bevlane-j6/v035_3_j6/bsl_aug.py#L74-L79) `depth: [1.0, 165.0, 1.0]`：深度从 1m 到 165m、固定 1m 一档。纯视觉（`use_lidar=False`）下，150m 处车道线只有几个像素，深度不确定性很大；而远端点的纵向坐标几乎完全由深度决定，1m 的深度量化误差直接变成 1m 的 x 误差，与 1.2m 的 x voxel 叠加。

### 5. 其它叠加因素

- **decoder 只有 2 层**（[bsl_aug.py:96](configs/psd-bevlane-j6/v035_3_j6/bsl_aug.py#L96) `num_decoder_layer=2`），MapTR/MapQR 类通常用 6 层做迭代 refine，2 层对远端点的迭代修正不足。
- **训练数据抽稀**（[bsl_aug.py:583](configs/psd-bevlane-j6/v035_3_j6/bsl_aug.py#L583) `load_interval=4`）可能进一步稀释"远端+弯道"这类难样本的占比。
- 远端在虚拟图里处于低分辨率/大畸变区（`virtual_fov=(22.4,12)`、`(110,56.2)`，`downsample=16`）。

## 二、优化方向（按性价比排序）

| 优先级 | 方向 | 具体做法 |
|---|---|---|
| ★★★ | 各向同性回归 loss | 在 `loss_single` 里对 `pts_targets`/`pts_preds` 先 denormalize 到物理米制再算 L1，或给 x、y 通道按 `patch_w/patch_h` 重加权；让纵向误差被同等惩罚 |
| ★★★ | 距离/曲率加权 loss | 给 20 个点按到 ego 的距离（或按弧长曲率）加权，远端权重更高；可做成 focal-style 或按深度加权 |
| ★★☆ | 增加采样点 / 非均匀采样 | `fixed_ptsnum_per_gt_line` 20→40/50，或对弯道区域加密采样（曲率自适应），配合增大 `num_pts_per_vec` |
| ★★☆ | 加强方向/曲率监督 | 提高 `loss_dir`/`loss_dir2` 权重（如 0.05~0.2），或显式加二阶曲率损失（相邻向量夹角变化量的 L1） |
| ★★☆ | 提高纵向 BEV 分辨率 | x voxel 1.2m→0.6/0.3m（代价是显存/算力），或 x 方向用非均匀（近密远疏）栅格 |
| ★★☆ | 深度监督/非均匀深度 bin | 用 log 分布深度 bin（近处密、远处疏），或加深度辅助 loss（若有伪深度） |
| ★☆☆ | 增加 decoder 层数 | `num_decoder_layer` 2→6，配合 `return_intermediate=True` 的逐层 loss |
| ★☆☆ | 数据侧补样 | 针对性增加急弯+远端样本，或降低 `load_interval` |

## 三、建议的验证方式

先把改动收敛到**可控、可量化**的验证闭环：
1. 写一个按"距离分段（如 0–30 / 30–60 / 60–100 / 100–153.6m）+ 曲率分段"统计 x/y 误差的评测脚本，确认误差是否集中在远端的**纵向 x 方向**（我预判是 x 主导）——这能直接验证上面第 1、4 条归因。
2. 先只改**各向同性 loss**（最小改动）单独训一版对比，再叠加**距离加权**，各出一次 eval 看分段误差曲线。
